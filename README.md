# 每日新闻早报 · 数据源

这个仓库只存放「每日新闻早报」网页里“今日速览”一栏的数据。

- `data.json`：每天由 GitHub Actions 自动更新，抓取中国新闻网滚动新闻，只保留健康、社会、财经、生活、教育等民生频道，并按价格、医保、社保、就业、住房、交通、天气、食品安全等关键词筛选。
- `scripts/fetch_news.py`：抓取与筛选脚本（仅用 Python 标准库）。
- `.github/workflows/update.yml`：每天北京时间 07:20 运行一次，也可手动触发。

筛选逻辑刻意避开时政、国际、军事、体育与娱乐条目，保证页面上只出现与普通人生活相关的内容。
